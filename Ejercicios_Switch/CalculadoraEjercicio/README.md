# Calculadora-CSharp

## Descripción
Este proyecto consiste en una calculadora básica desarrollada en C# como aplicación de consola.

El programa permite al usuario realizar las cuatro operaciones matemáticas principales utilizando dos números ingresados por teclado.

## Funcionalidades
- Suma
- Resta
- Multiplicación
- División
- Validación para evitar división entre cero
- Menú interactivo para seleccionar la operación

## Tecnologías utilizadas
- C#
- .NET
- Visual Studio

## Cómo ejecutar el proyecto

1. Clonar el repositorio.
2. Abrir el proyecto en Visual Studio.
3. Ejecutar el programa.
4. Seleccionar una operación e ingresar los números solicitados.
