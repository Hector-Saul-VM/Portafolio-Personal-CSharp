## Proyectos Destacados

### SistemaGestionEmpleados (API)
- **Descripción:** API completa con CRUD, DTOs, servicios y Swagger.
- **Tecnologías:** C#, ASP.NET Core, Entity Framework, SQL Server.
- `SistemaGestionEmpleados/`

### RegistroEstudiantes
- **Descripción:** Sistema de registro de estudiantes con archivo binario.
- **Tecnologías:** C#, .NET, archivos binarios.
- `RegistroEstudiantes/`

### InvertirOrdenPalabras
- **Descripción:** Invierte el orden de las palabras de una frase.
- **Ejemplo:** `"Hola mundo"` → `"mundo Hola"`
- `Ejercicios_Logica/InvertirOrdenPalabras/`

### ContarPalabrasRepetidasBucles
- **Descripción:** Cuenta cuántas veces aparece cada palabra.
- **Ejemplo:** `"hola mundo hola"` → `hola: 2, mundo: 1`
- `Ejercicios_Logica/ContarPalabrasRepetidasBucles/`

### ClasificadorNumerosCentinela
- **Descripción:** Clasifica números en positivos/negativos. Termina con 0.
- 📁 `Ejercicios_Logica/ClasificadorNumerosCentinela/`

### ParentesisBalanceados
- **Descripción:** Verifica si los paréntesis están balanceados.
- 📁 `Ejercicios_Logica/ParentesisBalanceados/`

### AdivinaNumerosConRandom
- **Descripción:** Juego donde adivinas un número aleatorio.
- 📁 `Ejercicios_While/AdivinaNumerosConRandom/`

### EjerciciosIfElse
- **Descripción:** Colección de ejercicios con condicionales.
- Incluye: FizzBuzz, Números primos, Divisiones, Positivo/Negativo.
- 📁 `EjerciciosIfElse/`

### Ejercicios_Switch
- **Descripción:** Colección de ejercicios con Switch.
- Incluye: Calculadora, Calificaciones, Colores RGB, Días de semana, Tipos de vehículo.
- 📁 `Ejercicios_Switch/`
